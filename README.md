# 油罐车变位场景下的工业计量偏差校正建模

> 横向科研项目 · 纯数学建模（无机器学习依赖）

## 一、项目背景

油罐车装卸油品时以**流量计读数**为计量依据，但流量计与油罐内实际油量存在系统性偏差。
本项目建立**椭圆截面卧式油罐的液体体积几何模型**：仅凭油罐几何参数（长/宽/高）、
油位探针读数与罐体双向倾角，即可精确计算罐内液体体积，
并用"装车体积 = 卸车体积"的物理约束对模型进行**仓级校正**。

**核心成果**：8 辆车、3487 条有效装卸记录的整体平均相对误差 **2.0366%**
（中位数 0.9989%，逐车 0.33%~3.66%），逐车指标见 `output/summary.csv`。

## 二、几何模型

油罐为卧式椭圆截面柱体，倾斜时液面（水平面）在罐体坐标系中是一个平面。

```
                    液体体积 = 平面(液面) 与 椭圆柱底面 之间的体积

        z ↑                         液面（水平面）
          │         ~~~~~~~~~~~~~ ~~~~~~~~~~~~~
          │        /                 /
     b ───┼──────/───── 椭圆截面 ───/───
          │     /        ··       /
        ──┼────/──────────·──────/──────────→ y
          │   /   d_y     ·     /
       -b ┼──/────────────·────/
          │            探针位置
          └────────────────────────────→ x  (罐体长度方向，探针处为原点)
```

### 模型假设与符号

| 符号 | 含义 |
|------|------|
| `width` / `height` | 椭圆截面的宽（长轴）与高（短轴），半轴 `a = width/2`、`b = height/2` |
| `L` | 罐体长度 |
| `d_c` | 油位探针到罐头的距离 |
| `d_y` | 探针偏离截面中心线的横向距离（数据表中的 `-X` 列） |
| `h` | 探针实测油高 |
| `α` | 纵向倾角（罐头-罐尾连线方向） |
| `β` | 横向倾角（截面宽度方向） |

### 计算步骤

1. **探针液位折算到中心线**（探针不在截面中心，且罐体横向倾斜）：

   `H = h + d_y·tanβ + b − |C_z|`，其中 `C_z = b·√(1−(d_y/a)²)` 是探针正下方椭圆边界的 z 坐标。

2. **液面方程**：罐体坐标系中液面是平面，任意位置 `(x, y)` 处液面相对椭圆中心的高度

   `z_surface(x, y) = (H − b) − x·tanα − y·tanβ`

3. **液柱高度**：液面与椭圆上边界取小者，减去下边界，且不为负

   `zA(x, y) = max( min(z_surface, +b·√(1−(y/a)²)) − (−b·√(1−(y/a)²)), 0 )`

4. **二重积分**：在椭圆投影区域上对 zA 做梯形法数值积分，x 的积分区间为
   `[−d_c, L−d_c]`（探针处为原点）。实现上使用 numpy 向量化网格计算，
   200×100 的网格在精度与速度之间取得平衡。

## 三、校正方案

对**每个仓**单独拟合一个体积校正系数 `k ∈ [0.90, 1.10]`，使得

```
min_k  median(|V1 − k·V2| / V1) + 0.01·|k−1|
```

- **为什么用中位数**：个别异常记录（如司机未排空罐体）不会主导目标函数；
- **为什么加正则化**：`0.01·|k−1|` 让 k 尽量接近 1，防止在小样本上过拟合出极端系数；
- **采用条件**：改进超过 0.1% 才启用新系数，否则保持 k=1（不校正）；
- 有效记录少于 20 条的仓不做优化。

## 七、设计问答（FAQ）

- 液面为什么是平面而不是曲面？→ 液体表面在重力作用下为等势面，静止时近似水平面。
- 为什么需要校正系数？→ 图纸参数与实际加工尺寸有偏差（焊接变形、椭圆度误差），
  且误差是系统性的，故用比例系数吸收。
- 数值积分的精度如何保证？→ 网格加密可收敛；梯形法对光滑函数二阶收敛；
  200×100 网格下误差在 0.01% 量级，相对工艺要求足够。
